# Use the File panel and file tabs

Use the **File panel** for a selection-following look at files as you browse. Open a **file tab** when you want one file to remain in the center while you navigate elsewhere.

- [Inspect files in the File panel](./inspect-files-in-the-file-panel.md) explains what follows the Explorer selection, how metadata and the file representation share the panel, and when Phials avoids a duplicate representation.
- [Open files in file tabs](./open-files-in-file-tabs.md) explains persistent File mode, existing-tab reuse, pinning, closing, and session restoration.
