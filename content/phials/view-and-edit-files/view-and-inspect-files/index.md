# View and inspect files

Phials chooses a representation that fits the selected file. Use the **File panel** for quick, selection-following inspection, or open a **file tab** when you want the file to remain in the center while you browse elsewhere.

Start with [Inspect files in the File panel](../use-the-file-panel-and-file-tabs/inspect-files-in-the-file-panel.md) or [Open files in file tabs](../use-the-file-panel-and-file-tabs/open-files-in-file-tabs.md) if those surfaces are new to you. Then use the format-specific article below for the controls and limitations of the representation you see.

- [View images and graphics](./view-images-and-graphics.md)
- [Play audio and video](./play-audio-and-video.md)
- [Read PDFs and text-based files](./read-pdfs-and-text-based-files.md)
- [Browse spreadsheets and databases](./browse-spreadsheets-and-databases.md)
- [Inspect folders and technical projects](./inspect-folders-and-technical-projects.md)
- [Inspect apps, executables, disk images, and archives](./inspect-apps-executables-disk-images-and-archives.md)
- [View fonts and 3D models](./view-fonts-and-3d-models.md)
- [Handle files Phials cannot display](./handle-files-phials-cannot-display.md)

These articles describe how to inspect files, not every supported extension. Use [File viewing and editing support](../../reference/file-format-and-metadata-support/file-viewing-and-editing-support.md) for the complete format matrix, [Metadata support by file type](../../reference/file-format-and-metadata-support/metadata-support-by-file-type.md) for extracted fields, and [Thumbnail support by file type](../../reference/file-format-and-metadata-support/thumbnail-support-by-file-type.md) for Grid and Gallery coverage.

When a representation can also change a file, the procedure belongs under [Edit files in Phials](../edit-files-in-phials/index.md). Inspection-only surfaces do not add editing controls merely because the same file is editable elsewhere.
