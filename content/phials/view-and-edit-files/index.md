# View and edit files

Select a file for a quick look in a panel, or open it in a persistent file tab when you want more room. Phials chooses an appropriate built-in viewer or editor when one supports the file.

- [Use the File panel and file tabs](./use-the-file-panel-and-file-tabs/index.md) explains the selection-following File panel and persistent file tabs.
- [Use Pages](./use-pages/index.md) covers the Page panel, Page mode, and Page property presentation.
- [View and inspect files](./view-and-inspect-files/index.md) explains practical controls and boundaries for supported viewer families.
- [Edit files in Phials](./edit-files-in-phials/index.md) covers the formats Phials can change and how each editor saves or reverts work.
