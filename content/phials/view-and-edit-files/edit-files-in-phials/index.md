# Edit files in Phials

Phials can edit several kinds of file content directly. The editing surface and save behavior depend on the format: Markdown autosaves, while source files, images, spreadsheets, and audio tags require an explicit **Save**.

Start with the file content you need to change:

- [Edit Markdown files](./edit-markdown-files.md) in a block editor or as Markdown source, with autosave and conflict recovery.
- [Edit text, code, HTML, and SVG](./edit-text-code-html-and-svg.md) with syntax-aware source editing and explicit Save or Revert.
- [Edit images](./edit-images.md) to annotate, crop, rotate, resize, or convert a supported raster image.
- [Edit spreadsheets](./edit-spreadsheets.md) to change grid data across flat files and workbook sheets.
- [Edit audio tags](./edit-audio-tags.md) to write embedded descriptions, credits, identifiers, lyrics, and cover art.

For read-only controls and viewer behavior, see [View and inspect files](../view-and-inspect-files/index.md). For an exact support matrix, see [File viewing and editing support](../../reference/file-format-and-metadata-support/file-viewing-and-editing-support.md).
