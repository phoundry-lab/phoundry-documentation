# Use Pages

A **Page** keeps a file's Workspace Folder properties and Markdown context in one presentation. The **Page panel** follows your Explorer selection, while **Page mode** keeps one file open in a file tab.

Use the Page panel when you want to move through files and inspect each Page in turn. Open Page mode when you want more room or need the Page to remain available while you browse elsewhere.

- [View a selected file's Page](./view-a-selected-files-page.md) to understand the selection-following panel and the content it presents.
- [Open a Page in a file tab](./open-a-page-in-a-file-tab.md) to keep a Page open and switch between File and Page modes.
- [Choose which properties appear on Pages](./choose-which-properties-appear-on-pages.md) to set Page-specific property visibility, order, and density for a Workspace Folder.

For writing in the Page body or connecting files through properties, see [Add notes and connect files](../../organize-files-with-phials/add-notes-and-connect-files/index.md).
