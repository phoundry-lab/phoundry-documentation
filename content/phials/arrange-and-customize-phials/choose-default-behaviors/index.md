# Choose default behaviors

Set the app-wide starting point for common actions while leaving room for a more specific choice when you need one. These preferences do not move, rename, or edit your files.

- [Choose new-tab and folder defaults](./choose-new-tab-and-folder-defaults.md) to set where a new Explorer tab starts and how an otherwise unconfigured folder is presented.
- [Choose which files appear](./choose-which-files-appear.md) to control hidden files, extensions, the parent entry, folder ordering, and always-hidden patterns.
- [Choose how files open](./choose-how-files-open.md) to choose a persistent primary-open action for each supported extension.
- [Configure thumbnails and media behavior](./configure-thumbnails-and-media-behavior.md) to balance thumbnail quality, storage, and generation work, then find the format-specific playback controls.

These are fallback behaviors, not replacements for live or named configurations. Use [Configure a file view](../../browse-and-manage-files/choose-and-configure-file-views/configure-a-file-view.md) for the active Explorer tab, [Save and reuse views](../../organize-files-with-phials/save-and-reuse-views/index.md) for named presentation configurations, and **Open in…** for a one-time choice of external app.
