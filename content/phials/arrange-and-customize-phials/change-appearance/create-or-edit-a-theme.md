# Create or edit a theme

Use the Theme Editor on desktop to make your own version of a built-in or community theme. Changes apply as you work so you can see them across your Phials windows.

1. In **Settings → This Client → Appearance**, choose **Open Editor**.
2. Choose **Duplicate Existing**, find a theme you like, and choose **Duplicate**. To return to one you made earlier, choose **Edit Custom Theme**, then **Edit**.
3. Under **Details**, give it a name and choose **Light** or **Dark**.
4. Open a setting in the list to adjust it. If you prefer to work with CSS, edit the theme directly in the right-hand pane.

The Theme Editor saves your changes automatically. The theme you’re editing becomes active. Choose **Themes** to go back to the list, or return to **Appearance** to choose a different theme.
