# Find and install community themes

Browse themes made by the Phials community and choose an appearance you like. You can install a theme while community plugins safe mode is on.

## Install and apply a theme

1. Open **Settings** and choose **Appearance** under **This Client**.
2. Choose **Browse Themes**.
3. In **Browse**, search for a theme or open its card to see more about it.
4. Choose **Install**.
5. Switch to **Installed** and choose **Apply** to use it right away. You can also select the theme from **Light Theme** or **Dark Theme** in Appearance.

Applying a theme also switches Phials to that theme’s light or dark color scheme. To switch automatically with your device’s appearance, set **Color Scheme** back to **System**.

## Update or remove a theme

If a theme has a newer version, choose **Update** in **Browse**.

To remove a theme, open **Installed**, choose the trash button on the theme’s card, then choose **Uninstall**. If the theme was selected, Phials switches that light or dark choice back to its default theme.
