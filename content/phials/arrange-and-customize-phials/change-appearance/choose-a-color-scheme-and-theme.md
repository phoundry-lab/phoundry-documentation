# Choose a color scheme and theme

Choose whether Phials follows your system's light or dark appearance, then choose a separate **theme** for each mode. Phials saves all three choices.

## Choose light or dark appearance

1. Open **Settings**.
2. Under **General**, choose **Appearance**.
3. Choose a **Color Scheme**:
   - **System** follows your operating system. Phials switches between your chosen light and dark themes when the system appearance changes.
   - **Light** keeps the light theme active.
   - **Dark** keeps the dark theme active.

The change takes effect immediately.

## Choose a theme for each mode

Use **Light Theme** and **Dark Theme** to choose the appearance Phials uses in each mode. Each list contains themes made for that mode and shows a small background, text, and accent-color sample.

The description for the theme in use includes **(Active)**. Changing that theme updates Phials immediately. You can also change the inactive theme in advance; Phials uses it the next time its matching color scheme becomes active.

An enabled community plugin can contribute additional light or dark themes. Its themes appear in the matching list and are available only while that community plugin is enabled. To add one, see [Find and install community plugins](../use-tools-and-community-plugins/find-and-install-community-plugins.md).
