# Adjust the interface zoom

Scale the complete Phials interface when text and controls are too small or when you want more information to fit in the window. Interface zoom changes tabs, panels, file views, text, and controls together.

## Change the zoom

Run one of these commands from the main Phials window:

| Command | Default shortcut | Result |
| --- | --- | --- |
| **Zoom In** | `Command+=` on macOS; `Ctrl+=` on Windows and Linux | Increases the current scale by about 10%. |
| **Zoom Out** | `Command+-` on macOS; `Ctrl+-` on Windows and Linux | Decreases the current scale by about 10%. |
| **Reset Zoom** | `Command+0` on macOS; `Ctrl+0` on Windows and Linux | Returns the interface to 100%. |

You can run the commands from the Command Bar even if you have changed or removed their shortcuts. Phials limits interface zoom to 50%–300% and ignores further changes at either limit.

Phials saves the zoom level and reapplies it on later launches. To assign different shortcuts, see [Change keyboard shortcuts](../customize-commands-and-shortcuts/change-keyboard-shortcuts.md).

Interface zoom does not change your files or exported content. It is also separate from image-viewer zoom and from item-size controls in individual file views; use those controls when you want to resize only that content.
