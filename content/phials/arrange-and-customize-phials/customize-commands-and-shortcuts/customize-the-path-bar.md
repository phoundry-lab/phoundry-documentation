# Use the Explorer toolbar

Use the path bar to see where you are and to move between folders. Choose part of the path to open that folder. For more ways to move around, see [Navigate folders and paths](../../browse-and-manage-files/navigate-locations/navigate-folders-and-paths.md).

Use the toolbar to [configure the current view](../../browse-and-manage-files/choose-and-configure-file-views/configure-a-file-view.md) or [search, sort, group, and filter files](../../browse-and-manage-files/find-and-narrow-files/index.md).

To keep a frequently used command within reach, [add it to an Explorer context menu](./customize-explorer-context-menus.md) or [assign a keyboard shortcut](./change-keyboard-shortcuts.md).
