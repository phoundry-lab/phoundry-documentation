# Find and run commands with the Command Bar

Use the **Command Bar** to find and run an action without first adding it to the Path Bar, an Explorer context menu, or a keyboard shortcut.

## Open and search the Command Bar

1. Press `Command+P` on macOS or `Ctrl+P` on Windows and Linux.
2. Type part of the command's name or related words from its description or category.
3. Choose the command, or use the Up and Down Arrow keys to highlight it and press Enter.

When the search box is empty, up to five recently run commands appear under **Recent**. The remaining commands are arranged by category. A shortcut shown at the right of a command is its current assignment, including any change you made in Settings.

Some rows have a chevron instead of running immediately. Open one to browse its related command group, then choose a command inside it. Press Escape or choose **Back** to return to the main command list. From the main list, press Escape to close the Command Bar.

## Availability follows the active context

The Command Bar uses the active Explorer tab, current selection, and other open Phials surfaces to decide which commands apply. A selection-specific command may be absent until you select a file, and a command that becomes unavailable before it runs has no effect.

If you cannot find an action, close the Command Bar, make the relevant Explorer tab or surface active, prepare the required selection, and open it again. Commands supplied by an active community plugin use the same list.

To make an action quicker to repeat, [change its keyboard shortcuts](./change-keyboard-shortcuts.md) or [add it to the Path Bar](./customize-the-path-bar.md). For the complete shipped command inventory, see the [built-in command reference](../../reference/commands-and-keyboard-shortcuts/built-in-command-reference.md).
