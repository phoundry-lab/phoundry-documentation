# Customize commands and shortcuts

**Commands** are named Phials actions. You can run an available command from the Command Bar, keep frequent actions in the Path Bar or Explorer context menu, and assign the keyboard shortcuts that suit your workflow.

- [Find and run commands with the Command Bar](./find-and-run-commands-with-the-command-bar.md) when you know the action you want but do not need a permanent button or shortcut.
- [Customize the Path Bar](./customize-the-path-bar.md) to place commands after the breadcrumb, change their presentation, or collect commands in a dropdown.
- [Customize Explorer context menus](./customize-explorer-context-menus.md) to control the shared order and visibility of actions shown for files, folders, selections, and empty space.
- [Change keyboard shortcuts](./change-keyboard-shortcuts.md) to add, remove, or restore as many as three bindings for each command.

For complete command and factory-shortcut lookup, use [Commands and keyboard shortcuts](../../reference/commands-and-keyboard-shortcuts/index.md).
