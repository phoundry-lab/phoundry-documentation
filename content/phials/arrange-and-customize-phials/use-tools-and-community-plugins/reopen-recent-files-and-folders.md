# Reopen recent files and folders

Use the **Recents panel** to return to locations and files you recently used in Phials. It keeps the 100 most recent entries, newest first, and shows each item's containing path and last-use time.

## Add and use the Recents panel

Open a dock's panel options menu, choose **Add panel**, then choose **Recents**. Recents can occupy the left, right, or bottom dock.

Choose an entry:

- A folder opens that location in a suitable Explorer tab.
- A file opens its containing folder and selects the file. It does not open a file tab; open the selected file when you want to view or edit it.

Phials adds or moves an entry to the top when you navigate to a folder or create, open, or save a file. Creating a folder also adds it. Renames and deletions performed in Phials update or remove the corresponding entries.

## Handle an unavailable entry

Recents does not monitor changes made by another app. If a file or folder was moved, renamed, deleted, or disconnected outside Phials, its old entry can remain. Choosing it may fail to navigate or may open a folder without selecting the expected file.

The Recents panel does not provide controls to remove one entry or clear the list manually. Entries age out after 100 newer items; deleting an item through Phials removes its matching entry.
