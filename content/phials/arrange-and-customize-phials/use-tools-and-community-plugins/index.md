# Use tools and community plugins

Phials includes tools for command-line work, recent locations, documentation, and guided learning. You can also choose to install code shared by the community after reviewing its source and access.

- [Use the Terminal](./use-the-terminal.md) to run independent shell sessions inside a dock or tab group.
- [Reopen recent files and folders](./reopen-recent-files-and-folders.md) from the Recents panel.
- [Get help inside Phials](./get-help-inside-phials.md) through bundled documentation, tutorials, and contextual help.
- [Find and install community plugins](./find-and-install-community-plugins.md) after deciding whether to turn off safe mode and trust third-party code.
- [Manage community plugins safely](./manage-community-plugins-safely.md) to review access, update, disable, or uninstall what you added.
