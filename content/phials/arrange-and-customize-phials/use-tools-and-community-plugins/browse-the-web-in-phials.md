# Browse the web in Phials

On desktop, choose **Web Browser** in the Command Bar, type a web address in **Enter URL**, and press Enter. Use **Back**, **Forward**, and **Reload** to move through pages. Choose **Open in system browser** to continue in your usual browser.

If you want the page beside an Explorer tab, move its tab into a [split view](../arrange-your-window/create-tab-groups-and-split-views.md). You can also add **Web Browser** to a dock from **Add panel**.

On iOS, web links open in your browser.
