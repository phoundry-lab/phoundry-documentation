# Get help inside Phials

Choose **Help** in the Command Bar or press `F1` to open the online Phials guide. On desktop, it opens in a browser tab inside Phials. On iOS, it opens in your browser.

Use the guide’s sidebar to browse by topic, or search for a feature, command, or setting. If you build plugins, open the [Plugin SDK documentation](/phials-developer) from the documentation site.
