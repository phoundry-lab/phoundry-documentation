# Get help inside Phials

Use the Help tab for complete documentation, the Learning panel for guided walkthroughs, or contextual help when you need a short explanation of a visible control.

## Browse the Help tab

Choose **Help** from the Command Bar or press `F1`. Phials creates one Help tab or focuses the existing one, so running the command again does not create duplicates.

Help opens the **User** documentation by default. Use the sidebar to browse outcome sections, topic hubs, and articles. A group label opens that group's introduction; its separate disclosure control expands or collapses the branch. Use the breadcrumb trail above the article to return to a parent topic.

Choose **Developer** at the end of the Help toolbar when you need extension-development documentation. During the current Help session, Phials remembers the last page you visited in each set. After a restart, Help returns to **User** documentation and restores its last saved user page when available.

The documentation is bundled with Phials and works offline. Links between articles stay in the Help tab; links to websites open in your system browser.

## Start or replay a tutorial

Add **Learning** from a dock's **Add panel** menu. The panel lists the available tutorials and marks completed ones with a check.

1. Choose a tutorial.
2. Review its step list.
3. Choose **Start**. If you stopped partway through during this Phials session, choose **Resume** to continue or **Restart** to begin again. A completed tutorial offers **Replay**.

Closing a tutorial after its first step keeps its resume point only for the current app session. **Skip tour** marks it complete instead. Completion marks remain available after restart.

The **Workspaces** guided demo creates a real `Phials Demo` folder in your home folder after you choose **Create Demo Workspace Folder**. Once that folder exists, closing, skipping, or finishing the tutorial asks whether to **Keep it** or **Delete demo Workspace Folder**. Deleting moves the demo folder and its Phials data to Trash; keeping makes it an ordinary Workspace Folder that you own.

## Reveal contextual help

Hold Option on macOS or Alt on Windows and Linux for a moment. Phials outlines visible controls that have contextual help.

- Hover over an outlined control for a short explanation.
- While continuing to hold the key, click an outlined control for more detail. That click opens help instead of operating the control.
- Choose **Read more** when it appears to open the related article in Help.
- Release Option or Alt to dismiss the outlines and any open explanation.

Contextual help covers selected controls in the main Phials window, not every row, menu, or Settings control. It is unavailable while a tutorial is open so the two guidance layers do not overlap.
