# Manage files and folders

Phials provides the familiar file-management actions you expect, plus utilities for working across Explorer tabs and Workspace Folders. These articles focus on where Phials behaves differently from your system's file manager.

- [Create and rename files and folders](./create-and-rename-files-and-folders.md) with Phials-aware updates to open views and saved locations.
- [Move, copy, and link files](./move-copy-and-link-files.md) by dragging or using the clipboard.
- [Open files in Phials or another app](./open-files-in-phials-or-another-app.md) for one file or as a lasting default.
- [Move files to Trash](./move-files-to-trash.md) and find them again through your system Trash.
- [Compress and extract archives](./compress-and-extract-archives.md) in ZIP, TAR, and 7Z formats.
- [Flatten folder contents](./flatten-folder-contents.md) when you need to remove one level of folder structure.
