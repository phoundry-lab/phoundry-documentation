# Open files in Phials or another app

The primary open action follows the behavior saved for that file extension. Use **Open in…** when you want a different app for one occasion without changing that behavior.

## Use the primary open action

Select a file and press `Enter`, double-click it, or choose **Open**. Depending on the file type and your preferences, Phials will:

- Open a supported file in a file tab
- Start supported audio in the audio player
- Send the file to its system-default app
- Send the file to an app you previously chose for that extension

Opening a folder navigates the Explorer tab to that folder.

To change what the primary action does for a file extension, see [Choose how files open](../../arrange-and-customize-phials/choose-default-behaviors/choose-how-files-open.md).

## Open one file in another app

1. Select one file.
2. Choose **Open in…**.
3. Choose an available app.

This choice applies only to that open. It does not change the saved behavior for the extension. If no other app is registered for the file type, Phials reports that none are available.

## Reveal an item on your system

Select a file or folder and choose the platform-specific file-manager action:

- **Open in Finder** on macOS
- **Open in File Explorer** on Windows
- **Open in File Manager** on Linux

Your system file manager opens with the item revealed. This is useful when you need an operating-system action that Phials does not provide.
