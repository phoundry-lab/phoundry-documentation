# Find and narrow files

Use sorting and grouping to reorganize a File view, filtering to hide items that do not meet your conditions, or search to scan filenames and file contents beyond the current listing.

Each Explorer tab owns its live sort, filter, group, and search state. A **saved view** keeps a File view configuration, while a **saved search** keeps a search query and its search-specific filters.

- [Sort files](./sort-files.md) by one field or a sequence of fields.
- [Filter files](./filter-files.md) with conditions and nested AND/OR logic.
- [Group files](./group-files.md) into collapsible sections without changing the active sort.
- [Search filenames and file contents](./search-filenames-and-file-contents.md) in one folder or across your home folder.
- [Save and reuse searches](./save-and-reuse-searches.md) from the Navigator.
