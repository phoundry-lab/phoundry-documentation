# Use Notebook view

Use Notebook when you want to work through several files and keep their Pages in view. Choose **Configure view → View mode → Notebook**, then select a file in the list to see its Page beside it.

Under **Configure view → Preview**, choose what to show in the list. You can show each file’s thumbnail, show its Page content when you’re in a Workspace Folder, or hide the preview.

You can [write notes about a file](../../organize-files-with-phials/add-notes-and-connect-files/write-notes-about-files.md) or [choose which properties appear on Pages](../../view-and-edit-files/use-pages/choose-which-properties-appear-on-pages.md).
