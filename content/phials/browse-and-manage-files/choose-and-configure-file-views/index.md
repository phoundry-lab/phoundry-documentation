# Choose and configure file views

File views change how the same files are arranged in an Explorer tab. Choose a view for the task at hand, then adjust its visible properties and presentation without changing the files themselves.

| File view | Best for |
| --- | --- |
| [Details](./use-details-view.md) | Comparing files across sortable property columns |
| [Grid](./use-grid-view.md) | Browsing visual previews, notes, and property captions |
| [Columns](./use-columns-view.md) | Following a folder branch without repeatedly replacing the current path |
| [Boards](./use-boards-view.md) | Moving files through option-based properties such as Status |
| [Calendar](./use-calendar-view.md) | Seeing and rescheduling files by a date property |

Open **Configure view** in the toolbar to switch file views or change the active view. See [Configure a file view](./configure-a-file-view.md) for the shared controls.

Sorting, filtering, and grouping narrow or reorder the files supplied to a file view. They are configured separately; start with [Find and narrow files](../find-and-narrow-files/index.md).
