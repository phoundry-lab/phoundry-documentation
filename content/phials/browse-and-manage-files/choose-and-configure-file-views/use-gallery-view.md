# Use Gallery view

Gallery gives the selected file most of the Explorer tab and keeps nearby files within reach in a filmstrip.

1. Open **Configure view → View mode** and choose **Gallery**.
2. Choose a thumbnail to preview the file. Use the arrow keys to move through the filmstrip.
3. To change where the thumbnails appear, open **Configure view** and choose **Filmstrip side**. You can place it on any edge.

The large preview uses the same file support as the File panel. See [View and inspect files](../../view-and-edit-files/view-and-inspect-files/index.md) for what you can open.
