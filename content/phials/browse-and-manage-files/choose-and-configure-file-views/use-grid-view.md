# Use Grid view

Grid view presents files as visual tiles. Use it to scan thumbnails, read short note previews, or compare a small set of properties without the density of Details view.

Open **Configure view** in the toolbar, choose **View mode**, then choose **Grid**.

## Choose what each tile shows

Choose **Property visibility** in **Configure view**.

- **Name** controls whether the filename appears.
- Other visible properties appear as captions in the same order as the property list.
- Properties without a value are omitted from the tile.
- Drag visible properties to change the caption order.

Workspace Folder properties and built-in file information can both appear as captions. To set values on files, see [Set property values on files](../../organize-files-with-phials/describe-and-classify-files/set-property-values-on-files.md).

## Adjust tile size and shape

Under **View options** in **Configure view**:

- Choose **Item size** **S**, **M**, or **L**.
- Use **Thumbnail orientation** to choose **Landscape**, **Square**, or **Portrait** frames.
- Turn **Show card chrome** off for a lighter tile without the card background and border. The preview and captions remain available.
- Turn on **Compact properties** to place populated property captions inline and wrap them across the tile.
- Turn on **Colored Group Backgrounds** to tint tiles when the listing is grouped by an option-backed property.

## Choose the preview

Use **Preview** under **View options**:

- **Thumbnail** shows the file or folder thumbnail.
- **Note content** shows the beginning of the file's note, or the document body for a Markdown file. This option is available inside a Workspace Folder. A tile without note text shows **No note content**.
- **None** removes the preview area and leaves the filename and property captions.

Changing the preview only changes Grid view. It does not alter the file or delete a note.

## Edit properties from a card

Inside a Workspace Folder, point to a file card and choose **Edit properties** to change its visible custom properties without leaving Grid view. Built-in file information remains read-only.

Choose a tile once to select it. Open it in the usual way when you want the file itself rather than its card details.
