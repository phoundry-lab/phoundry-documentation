# Phials data and storage

Phials stores several different classes of data. **Phials Home** contains durable app-wide settings and state. A **Workspace Folder bundle** contains the data owned by one Workspace Folder. OS-managed caches contain work Phials can regenerate. Your ordinary files remain ordinary filesystem content outside those stores.

- [Phials Home and global app data](./phials-home-and-global-app-data.md) maps app-wide settings, databases, session state, installed plugins, and locally stored Workspace Folder bundles.
- [Workspace Folder data and portable bundles](./workspace-folder-data-and-portable-bundles.md) identifies the files that must stay together for one Workspace Folder.
- [Caches and temporary data](./caches-and-temporary-data.md) distinguishes safe-to-regenerate storage from durable data.
- [Back up and restore Phials data](./back-up-and-restore-phials-data.md) defines complete backup scopes and restoration order.

For the ordinary storage, movement, backup, and removal tasks for one Workspace Folder, see [Use Workspace Folders](../../organize-files-with-phials/use-workspace-folders/index.md).
