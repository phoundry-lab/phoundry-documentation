# File format and metadata support

Use these references to check what Phials can do with a particular file type. Support depends on both the file's extension and whether its contents can be decoded.

- [File viewing and editing support](./file-viewing-and-editing-support.md) lists the formats Phials can display, play, inspect, or edit, along with opening behavior and limits.
- [Metadata support by file type](./metadata-support-by-file-type.md) lists the structured information Phials can read from files and the audio tags it can write.
- [Thumbnail support by file type](./thumbnail-support-by-file-type.md) explains which files receive content thumbnails, generated representations, or ordinary file icons.

These pages are lookup tables. For controls and procedures, use [View and inspect files](../../view-and-edit-files/view-and-inspect-files/index.md) or [Edit files in Phials](../../view-and-edit-files/edit-files-in-phials/index.md).
