# Commands and keyboard shortcuts

Use these reference articles to find a shipped command or check its factory keyboard shortcut. Commands from community plugins are not included because they depend on which plugins you have active.

- [Built-in command reference](./built-in-command-reference.md) lists each user-facing command, what it does, when it is available, and where it normally appears.
- [Default keyboard shortcuts](./default-keyboard-shortcuts.md) lists factory bindings for macOS, Windows, and Linux, including commands that have no default binding.

To run commands or change how you reach them, see [Customize commands and shortcuts](../../arrange-and-customize-phials/customize-commands-and-shortcuts/index.md).
