# Troubleshoot Phials

Start with the narrowest action that matches the symptom. Refresh the affected location before clearing a cache, repair one settings or session store before resetting Phials, and collect diagnostic information before any last-resort recovery.

- [Fix file and folder access problems](./fix-file-and-folder-access-problems.md) when a location is missing, offline, protected, or denied by the operating system.
- [Refresh stale thumbnails and file information](./refresh-stale-thumbnails-and-file-information.md) when Phials shows an old representation or metadata value after a file changes.
- [Recover from settings or session problems](./recover-from-settings-or-session-problems.md) when a preference will not persist or unwanted window state returns after restart.
- [Inspect and share diagnostic information](./inspect-and-share-diagnostic-information.md) to capture a read-only snapshot and review private paths before sharing it.
- [Reset Phials safely](./reset-phials-safely.md) only after narrower recovery has failed and you have protected the durable data you need.

Problems specific to a task remain with that task. For example, server reconnection belongs with [Connect to a server](../../browse-and-manage-files/navigate-locations/connect-to-a-server.md), and unavailable Workspace Folder recovery belongs with [Move or reconnect a Workspace Folder](../../organize-files-with-phials/use-workspace-folders/move-or-reconnect-a-workspace-folder.md).
