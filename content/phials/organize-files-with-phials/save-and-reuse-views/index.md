# Save and reuse views

A **saved view** is a named presentation configuration for a folder. It can retain a view mode, sorting, filtering, grouping, item size, column arrangement, collapsed groups, and view-specific options. Switching saved views restores those choices without changing the files in the folder.

Use these articles to manage the complete saved-view lifecycle:

- [Create and switch saved views](./create-and-switch-saved-views.md) to capture the current presentation and move among named configurations.
- [Update or reset a saved view](./update-or-reset-a-saved-view.md) to keep deliberate changes or return to the stored configuration.
- [Rename, customize, duplicate, or delete a saved view](./rename-customize-duplicate-or-delete-a-saved-view.md) to manage a view's identity and lifecycle.
- [Add a saved view to subfolders](./add-a-saved-view-to-subfolders.md) to copy a configuration into separate ordinary-folder scopes.
- [Use saved views throughout a Workspace Folder](./use-saved-views-throughout-a-workspace-folder.md) to share one set of definitions across a folder tree.

Saved views preserve configurations you have already built. Use [Configure a file view](../../browse-and-manage-files/choose-and-configure-file-views/configure-a-file-view.md) for live view controls. A [saved search](../../browse-and-manage-files/find-and-narrow-files/save-and-reuse-searches.md) preserves a search, while a [Layout](../../arrange-and-customize-phials/arrange-your-window/save-and-reuse-layouts.md) preserves the complete center arrangement.
