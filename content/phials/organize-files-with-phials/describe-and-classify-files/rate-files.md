# Rate files

Add a **Rating** property when a one-to-five-star scale helps you compare files. Ratings are Workspace Folder data; Phials does not write them into the files' embedded metadata.

## Add the Rating property

1. Browse the folder you want to rate files in.
2. Choose **New** > **Add Property** > **Rating**.

If this is the first Workspace Folder feature used in the folder, Phials prepares the required data and continues. A Workspace Folder can have only one Rating property, so **Rating** becomes unavailable in the Add Property menu after you create it.

You can rename the property or choose a different icon through **Configure property…**. Rating does not have options or another scale to configure.

## Assign or clear stars

Show the Rating property in Details or Grid, or open the selected file's File or Page property list.

- Choose a star to set a rating from one to five.
- Choose the currently selected star again to clear the rating.

The change saves immediately. It applies only to the file you are editing, even when several files are selected.

## Use ratings in a file view

Once Rating is visible, you can use it like other numeric Workspace Folder properties:

- [Sort files](../../browse-and-manage-files/find-and-narrow-files/sort-files.md) by Rating to put the highest- or lowest-rated files together.
- [Group files](../../browse-and-manage-files/find-and-narrow-files/group-files.md) by Rating to create a section for each star value and for unrated files.
- [Filter files](../../browse-and-manage-files/find-and-narrow-files/filter-files.md) to keep only ratings that match your condition.

Ratings belong to this Workspace Folder. Another Workspace Folder can rate the same filesystem file independently.
