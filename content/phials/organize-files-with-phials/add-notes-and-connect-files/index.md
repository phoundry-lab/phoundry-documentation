# Add notes and connect files

Use a file's **Page** to keep Markdown and Workspace Folder properties together. A Page uses the file itself when it is Markdown; other files receive a separate per-file note. **Relations** connect files through a property, and **Rollups** summarize values from those connected files.

These features add Workspace Folder data without changing what an ordinary file contains. The exception is a Markdown file's Page body, which edits that Markdown file directly.

Start with the outcome you need:

- [Write notes about files](./write-notes-about-files.md) to add Markdown context to a file.
- [Connect files with Relations](./connect-files-with-relations.md) to choose related files in the same or another Workspace Folder.
- [Follow backlinks between files](./follow-backlinks-between-files.md) to understand the present incoming-connection limitation.
- [Summarize connected files with Rollups](./summarize-connected-files-with-rollups.md) to count, list, or calculate values from related files.

For the Page panel, Page mode, and Page-specific property visibility, see [Use Pages](../../view-and-edit-files/use-pages/index.md).
