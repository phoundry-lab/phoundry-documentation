# Organize files with Phials

Phials can store organization around your files without replacing the files themselves. When you first use a feature that needs this information, Phials prepares **Workspace Folder** data for that folder.

- [Save and reuse views](./save-and-reuse-views/index.md) preserves useful combinations of view, sort, filter, group, and column settings.
- [Describe and classify files](./describe-and-classify-files/index.md) covers properties, ratings, tags, statuses, and other values you add.
- [Add notes and connect files](./add-notes-and-connect-files/index.md) explains notes, Relations, backlinks, and Rollups.
- [Use Workspace Folders](./use-workspace-folders/index.md) covers identity, storage mode, portability, backup, recovery, and removal.
