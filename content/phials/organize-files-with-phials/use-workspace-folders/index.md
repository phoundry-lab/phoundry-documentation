# Use Workspace Folders

A **Workspace Folder** is a normal folder Phials has set up with **Workspace Folder data**, such as ratings, tags, properties, notes, relations, and saved views. The files and folders remain ordinary filesystem content. Phials stores the additional data separately and associates it with that folder.

When you first use a feature that needs Workspace Folder data, Phials prepares it for the folder and continues the action. You do not need to set up the folder as a separate prerequisite. This hub covers the choices you may make after setup:

- [Find and customize Workspace Folders](./find-and-customize-workspace-folders.md) to open a known folder, refresh discovery, or change its display name and icon.
- [Store Workspace Folder data locally or portably](./store-workspace-folder-data-locally-or-portably.md) to choose whether the data stays in Phials Home or travels inside the folder.
- [Move or reconnect a Workspace Folder](./move-or-reconnect-a-workspace-folder.md) to preserve its identity after a rename or location change.
- [Back up and restore Workspace Folder data](./back-up-and-restore-workspace-folder-data.md) to protect both the ordinary files and their Phials data.
- [Remove Phials data from a folder](./remove-phials-data-from-a-folder.md) to return a folder to ordinary use without deleting its files.

For the features that create and use this data, see [Save and reuse views](../save-and-reuse-views/index.md), [Describe and classify files](../describe-and-classify-files/index.md), and [Add notes and connect files](../add-notes-and-connect-files/index.md).
