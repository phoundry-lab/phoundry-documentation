# Phials Help

Phials is a file manager for browsing, viewing, editing, and organizing the files you already keep on your computer and connected storage. Use this guide to learn the parts of Phials that differ from your system file manager, then go directly to the task or reference you need.

- [Get started](./get-started/index.md) introduces what Phials can do, the main parts of the window, and the first-launch path.
- [Browse and manage files](./browse-and-manage-files/index.md) covers locations, everyday file operations, Explorer tabs, file views, and finding files.
- [Organize files with Phials](./organize-files-with-phials/index.md) explains saved views, properties, notes, connections, and Workspace Folders.
- [View and edit files](./view-and-edit-files/index.md) covers the File and Page surfaces, built-in viewers, and supported editing workflows.
- [Arrange and customize Phials](./arrange-and-customize-phials/index.md) shows how to arrange the window, change defaults, customize commands, and add community plugins.
- [Reference](./reference/index.md) provides detailed command, syntax, format, storage, and troubleshooting information.
