# Take notes and build knowledge around files

Keep explanations, decisions, and connections with the files they describe. A **Page** presents one file together with its Workspace Folder properties and a body you can read or edit. A **Workspace Folder** is a normal folder Phials has set up with extra data for its files.

For a Markdown file, the Page body is the file's own Markdown content. For another file in a Workspace Folder, such as a PDF, image, or spreadsheet, the body is a per-file note stored as Workspace Folder data. This distinction lets you write around an existing file without converting it, while a Markdown file remains the source of its own text.

A **property** is a reader-defined field that adds structured context such as a status, date, URL, or category. A **Relation** is a property that connects the current file to one or more files without moving or copying them. A **Rollup** is a read-only property that summarizes values from files connected through a Relation.

For example, a research paper can keep reading notes on its Page, connect to a summary or dataset through Relations, and show a Rollup of relevant values from those connected files. This is one possible workflow; Pages and connections can support any folder where context belongs with the files themselves.
