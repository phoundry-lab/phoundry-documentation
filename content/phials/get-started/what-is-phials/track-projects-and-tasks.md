# Track projects and tasks

Track work around the files a project already produces. A **Workspace Folder** is a normal folder Phials has set up with extra data for its files. Each file can carry reader-defined **properties**, such as Status, Date, Checkbox, Select, or Text, while remaining an ordinary file on disk.

The same folder can present that information in several ways. Details view gives you a column-based overview. Boards view groups files into columns using a property such as Status, Select, Multi-select, or Tags. Calendar view places files by a built-in file date or a Date property. Sorting, filtering, and grouping refine any working view, and a **saved view** preserves a useful configuration so you can return to it.

For example, a project folder might use a Status property to distinguish planned, active, and completed work, a Date property for deadlines, Boards view for workflow stages, and Calendar view for time-based review. A different project can use different properties and views; Phials does not impose one project method.

To define the information your project needs, see [Add and configure properties](../../organize-files-with-phials/describe-and-classify-files/add-and-configure-properties.md) and [Use Select, Multi-select, and Status properties](../../organize-files-with-phials/describe-and-classify-files/use-select-multi-select-and-status-properties.md). Learn how to [use Boards view](../../browse-and-manage-files/choose-and-configure-file-views/use-boards-view.md), [use Calendar view](../../browse-and-manage-files/choose-and-configure-file-views/use-calendar-view.md), or [create and switch saved views](../../organize-files-with-phials/save-and-reuse-views/create-and-switch-saved-views.md) when those presentations fit the work.
