# Review and organize media

Review images, audio, and video while keeping the original files in their folders. Grid view uses thumbnails for visual scanning, while Details and the File panel can show available **metadata** that Phials reads from a file or the filesystem, such as dimensions, duration, or embedded media information.

When a folder needs a review workflow, use **Workspace Folder data**: extra information Phials stores for files in a **Workspace Folder**, a normal folder it has set up for this purpose. Add a **Rating** property or **Tags**, then sort, filter, group, or build saved views around those values without writing the rating or tag into the original media file. Other reader-defined properties can record a review stage, date, or intended use.

Phials provides viewers for supported image, audio, and video formats. Supported editing is format-specific: raster images can be annotated, cropped, rotated, resized, or converted, while the audio tag editor can update supported embedded track information and cover art. Phials plays supported video formats but does not edit video content.

For viewing controls and format boundaries, see [View images and graphics](../../view-and-edit-files/view-and-inspect-files/view-images-and-graphics.md) and [Play audio and video](../../view-and-edit-files/view-and-inspect-files/play-audio-and-video.md). For organization, continue with [Rate files](../../organize-files-with-phials/describe-and-classify-files/rate-files.md) or [Tag files across Workspace Folders](../../organize-files-with-phials/describe-and-classify-files/tag-files-across-workspace-folders.md). See [Edit images](../../view-and-edit-files/edit-files-in-phials/edit-images.md) and [Edit audio tags](../../view-and-edit-files/edit-files-in-phials/edit-audio-tags.md) for supported changes.
