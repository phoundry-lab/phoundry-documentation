# Work with code and technical projects

Browse source trees, inspect technical folders, search code, and make focused edits without separating those files from the rest of a project. Phials recognizes many text and code formats and can present them with syntax highlighting in a file tab.

Text and code files can be edited in Phials when the format is supported. Filename and file-content search helps locate a definition, configuration value, or reference across a folder. When a folder is a Git repository, the File panel can summarize information such as its branch, remote, working-tree status, languages, and package details when those details are available.

The **Terminal** is a shipped Phials feature that can live in a dock or a center tab group. It gives command-line work a place beside the folders and files it affects. For language-specific tooling or another workflow Phials does not provide, open the file in the appropriate application and continue to use Phials for navigation and organization.
