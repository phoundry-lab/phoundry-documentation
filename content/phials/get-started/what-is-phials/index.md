# What is Phials?

Phials is a **file manager** for browsing and working with files and folders in the locations you already use. The essentials are familiar: navigate folders, manage items on disk, and open files in Phials or another app. Phials adds flexible file views, file-aware tools, and optional ways to describe and connect files without turning them into a separate library.
