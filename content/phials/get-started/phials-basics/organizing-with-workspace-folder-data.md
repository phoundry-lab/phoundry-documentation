# Organizing with Workspace Folder data

A **Workspace Folder** is a normal folder that Phials has prepared to store information around its files. Your ordinary files remain ordinary filesystem content. Phials adds **Workspace Folder data** such as saved views, properties, ratings, tags, notes, and Relations.

When you first use a Workspace Folder feature in an ordinary folder, Phials prepares the required data for that folder and continues the requested action. You do not need to reorganize or import the folder first.

## Information you define

A **property** is a field you define for files in one Workspace Folder. Properties can hold text, numbers, dates, choices, ratings, tags, and other structured values. A **Relation** connects one file to other files without moving, copying, or embedding them.

This information is different from **metadata**, which Phials reads from a file or the filesystem. A camera model read from an image is metadata; a review status you assign is a property.

Saved views remember useful combinations of view mode, sorting, filtering, grouping, and other presentation choices. Pages combine Workspace Folder properties with Markdown content or a note for each file.

## Where the data lives

By default, Phials stores Workspace Folder data in Phials Home, separately from the content folder. You can make a Workspace Folder portable when its Phials data needs to travel with the folder. Changing storage mode does not convert or relocate the ordinary files themselves.
