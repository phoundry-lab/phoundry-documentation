# Arranging your window

You can arrange Phials around the work you want visible without changing the files, folders, or Workspace Folder data behind it. Supporting tools can sit around the edges, while tabs occupy the center.

## Docks hold panels

The **left dock**, **right dock**, and **bottom dock** contain named **panels** such as Navigator, File, Page, Tags, and Terminal. You can show, hide, and resize docks. You can also move eligible panels between docks, group them as tabs, or place some of them in the center.

A panel keeps its purpose when it moves. For example, the File panel still follows the active Explorer selection whether it is in the left or right dock.

## Tab groups form split views

Every center tab belongs to a **tab group**. Moving tabs between groups or creating a group beside another one produces a **split view**. Each visible group presents its own active tab, while one group remains active for commands and keyboard focus.

Explorer tabs, file tabs, and eligible feature tabs can share this arrangement. Splitting the center does not create a second copy of a moved tab; it changes where that tab appears.

## Layouts remember the center

A **Layout** is a named, automatically saved complete center environment. It includes tab groups, tabs, Explorer state, split directions, and proportions. It does not include the left, right, or bottom docks.

Exactly one Layout is active, and center changes save into it as you work. Restart restoration opens that active Layout where you left it. A saved view is narrower: it remembers how files appear in one location.
