# Download and install Phials

Install the Phials build made for your computer, then open the app to choose a trial or activate a license.

## Choose the correct download

Use the official [Phials download page](https://phials.phoundry.app/download). It suggests a download for the operating system it detects and also shows the available platform choices.

| Platform | Available build |
| --- | --- |
| macOS | Apple Silicon and Intel |
| Windows | x64 for Windows 10 or later |
| Linux | No release build |

On a Mac, choose **Apple Silicon** for a Mac with an Apple M-series chip. Choose **Intel Mac** for a Mac with an Intel processor. If the download page cannot identify the Mac architecture, its main download action defaults to Apple Silicon; both choices remain available in the macOS card.

Phials does not provide a Linux installer. Use a supported Mac or Windows computer to run the desktop app.

## Install on macOS

1. Open the downloaded `.dmg` file.
2. Drag **Phials** to the **Applications** folder shown in the installer window.
3. Eject the Phials disk image.
4. Open **Phials** from Applications.

The macOS download is architecture-specific. If the app does not open because the build is incompatible with your Mac, remove that copy and install the other macOS build.

## Install on Windows

1. Open the downloaded Phials setup file.
2. Follow the installer prompts. Approve the Windows permission prompt if it appears.
3. Open **Phials** from the Start menu or the installer’s completion screen.

The Windows release is an x64 build. Phials does not provide a Windows ARM build.

When Phials opens, continue with [Start a trial or activate a license](./start-a-trial-or-activate-a-license.md).
