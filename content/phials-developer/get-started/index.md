# Get started

Start here to understand what a Phials plugin can add and reach a working local installation with the supported starter project. You need working knowledge of TypeScript, npm, Git, and component-based web development; prior Phials, Svelte 5, or Phoundry UI experience is not required.

- [Understand Phials plugins](./understand-phials-plugins/index.md) introduces capabilities, providers, lifecycle states, the public SDK, and the trust boundary.
- [Build your first plugin](./build-your-first-plugin/index.md) takes the plugin starter from a fresh checkout to an activated plugin and a visible first change.
- [Use Svelte and Phoundry UI](./use-svelte-and-phoundry-ui/index.md) covers the supported component patterns, shared interface library, styling, responsiveness, and accessibility.

After the first-plugin path works, use [Run your plugin locally](../test-and-troubleshoot/run-your-plugin-locally/index.md) for the complete repeatable development loop.
