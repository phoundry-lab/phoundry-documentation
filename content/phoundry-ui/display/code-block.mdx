## Styling

The stable root hook is `.ph-code-block` for both the fallback `pre` and the highlighted wrapper `div`. `class` and `style` target that root. `data-highlighted` is `false` while plain code is displayed and `true` when Shiki's markup is ready. The fallback and generated markup use local vanilla CSS; only generated `pre` and `code` descendants require bounded global selectors. `--ph-code-block-font` customizes the code font and defaults to the existing system monospace stack. Syntax colors follow the active named Theme; highlighting reacts to Theme changes and ignores stale async results.

Replace `.phi-code-block` and `.phi-code-block-fallback` identification hooks with `.ph-code-block` and `data-highlighted`. Internal part selectors and Shiki's DOM are not stable customization hooks.
