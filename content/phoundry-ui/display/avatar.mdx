## Usage tips

- The avatar falls back gracefully: image → initials → explicit `icon` → default user icon.
- If the image fails to load, the component automatically switches to the initials or icon fallback.
- Provide meaningful `alt` text whenever `src` is set; it defaults to an empty string.
- Use `status` alongside user avatars in chat, team lists, or collaboration UIs.

## Styling

`.ph-avatar` is the stable root hook. Consumer `class` values are additive, and `style` applies to that root. Styling uses vanilla CSS with semantic state attributes. Avatar intentionally retains its own scale: `xs` 1.5rem, `sm` 2rem, `md` 2.5rem, and `lg` 3.5rem. It does not consume the shared control-height tokens. Its initials, icon, and status-dot dimensions retain their previous proportions. The root emits `data-size`; the status part emits `data-status`. Image, initials, explicit icon, and default-user fallback precedence is unchanged. Internal part selectors and `--_ph-*` properties remain implementation details.
