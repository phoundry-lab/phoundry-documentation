## Usage tips

- Use the `label` prop for "or" dividers in forms (e.g. "Or continue with").
- Vertical separators need a parent with explicit height and `display: flex`.
- Pass a `children` snippet for custom center content (icons, badges, etc.).

## Styling

`.ph-separator` is the stable root hook. Consumer `class` values are additive, and `style` applies to that root. Styling uses vanilla CSS with semantic state attributes. The root always emits `data-orientation` and `data-has-label`, and uses the matching `aria-orientation` for separator semantics. Its one-pixel rule, vertical stretching, centered label, and snippet precedence are unchanged. Internal part selectors and `--_ph-*` properties remain implementation details.
