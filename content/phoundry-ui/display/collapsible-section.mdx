## Usage tips

- The header row uses `role="button"` with keyboard activation - ensure titles stay concise for screen readers.
- Use uncontrolled mode (just `defaultOpen`) for simple cases; use `open` + `onToggle` for external control.
- The `extraButtons` prop lets you add action buttons (e.g. "Add", "Edit") to the header row alongside the toggle.
- Set `contentPadding={false}` when embedding full-bleed content like tables or lists.
- Use `fullHeight` inside flex layouts where the section should stretch to fill remaining space.

## Styling

`.ph-collapse` is the stable root hook. Consumer `class` values are additive, and `style` applies to that root. Styling uses vanilla CSS with semantic state attributes. The header remains the `headerClass` target, exposes `aria-expanded`, and uses `data-title-variant` for default/sidebar typography. The root exposes `data-full-height`; content exposes `data-padded`. Existing controlled/uncontrolled callbacks, extra buttons, padding, and full-height behavior are preserved. Header actions appear on hover or keyboard focus within the header. Reduced motion skips the content transition. Internal part selectors and `--_ph-*` properties remain implementation details.
