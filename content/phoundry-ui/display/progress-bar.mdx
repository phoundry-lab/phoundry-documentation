## Usage tips

- Omit `value` or pass `-1` for an animated indeterminate bar.
- Use `variant="success"` when progress reaches 100% to reinforce completion.
- Enable `showValue` for file uploads or long-running tasks where users need exact progress.

## Styling

`.ph-progress` is the stable root hook. Consumer `class` values are additive, and `style` applies to that root. Styling uses vanilla CSS with semantic state attributes. The root emits `data-size` and `data-variant`; `role="progressbar"` and value attributes remain on the track. Values clamp to 0–100; omitted or negative values retain indeterminate semantics and omit `aria-valuenow`. Track thickness stays 0.25rem / 0.5rem / 0.75rem for `sm` / `md` / `lg`. Numeric progress is passed through an internal CSS property. Fill transitions use `--ph-motion-slow` (300ms), and indeterminate motion uses `--ph-motion-progress` (1800ms). Reduced motion removes both movement and transitions. Internal part selectors and `--_ph-*` properties remain implementation details.
