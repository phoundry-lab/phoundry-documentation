## Usage tips

- Pass a parsed object or array. Detection and `JSON.parse` belong in the Consumer.
- There is no wrapper `{` / `[` row. The tree starts at the value's own keys or indices.
- Nested string leaves stay strings. JsonTree does not sniff them again.
- Empty objects and arrays render as `{}` / `[]` leaves, not as blank fold rows.
- This is inspect-only. There is no selection and no drag.

## Styling

`.ph-json-tree` is the stable root hook. Consumer `class` values are additive, and `style` applies to that root. Styling uses vanilla CSS with semantic state attributes. The root remains a `tree`, nested lists remain `group` elements, and expandable rows retain their ARIA state and button controls. Top-level entries and collapsed-by-default nested containers behave as before. The shared `.ph-json-value` primitive maps `data-kind` to the active Theme’s syntax colors for both scalar roots and recursive leaves. Internal row selectors and DOM hierarchy are not customization APIs. Internal part selectors and `--_ph-*` properties remain implementation details.
