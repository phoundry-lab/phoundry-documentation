## Usage tips

- `Mod` resolves to ⌘ on macOS and Ctrl on other platforms.
- Keys are automatically uppercased and mapped to platform glyphs (e.g. ⇧ for Shift on Mac).
- Pair with command palette items, menu labels, or tooltip descriptions to show shortcuts inline.

## Styling

`.ph-kbd` is the stable root hook. Consumer `class` values are additive, and `style` applies to that root. Styling uses vanilla CSS with semantic state attributes. `variant="filled"` is the default and retains the current translucent keycap style. `variant="ghost"` removes the fill and text shadow while retaining the same keycap geometry. The root always emits `data-size` and `data-variant`. Keycap heights now consume `--ph-comp-h-sm` (1.5rem, previously 1.25rem) and `--ph-comp-h-md` (1.75rem). Platform-specific key formatting and PC separator labels are unchanged. `KbdVariant` is exported from `phoundry-ui`. Internal part selectors and `--_ph-*` properties remain implementation details.
