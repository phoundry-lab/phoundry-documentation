# Phoundry UI

Phoundry UI is a shared **Svelte 5** component library with overlay systems and
themed primitives, designed around use in desktop applications. Every page in
this documentation renders **live, interactive components** - what you see is the
real library running in your browser.

## Installation

Phoundry UI is distributed as the `phoundry-ui` package with plain CSS. No
utility CSS compiler or build plugin is required. Import the styles once in your root layout, then call `setupOverlays()` to
enable the modal, tooltip, context-menu, toast, and command-bar systems.

## Theming

The site theme selector switches documentation and examples between light and
dark appearances. Explore individual built-in palettes in the isolated gallery
in the [Theming guide](/phoundry-ui/guides/theming). That gallery uses the real
`ThemeManager` without changing the surrounding documentation.
