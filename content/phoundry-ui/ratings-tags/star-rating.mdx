## Usage tips

- Click a star to set the rating; click the same star again to reset to 0.
- With `allowHalf`, clicking the left half of a star sets a half-star value.
- Use `readonly` for display-only ratings (e.g. product reviews, averages).
- Use `size="xs"` for dense readonly rows (thumbnail captions, compact table cells); it uses tighter padding than larger sizes.
- Keyboard: Arrow keys adjust by 1 (or 0.5 with `allowHalf`), Home = 0, End = max.

## CSS styling

`.ph-star-rating` is the stable identification hook for StarRating. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

The rating-specific icon scale remains `xs` 0.75rem, `sm` 1rem, `md` 1.25rem, and `lg` 1.5rem. Rating and keyboard behavior are unchanged.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.
