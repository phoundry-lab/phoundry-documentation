## Usage tips

- Type a tag and press Enter or click Add. Use commas to add multiple tags at once.
- Backspace on an empty input removes the last tag.
- Duplicates are rejected automatically with an inline validation message.
- Pass an async function to `suggestions` for server-side typeahead (debounced at 200ms).

## CSS styling

`.ph-tag-editor` is the stable identification hook for TagEditor. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

Tag validation, limits, callbacks, and suggestion behavior are unchanged. Invalid fields and disabled controls retain their semantic state.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.
