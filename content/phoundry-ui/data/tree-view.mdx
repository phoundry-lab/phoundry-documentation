## Usage tips

- Use `nodeContent` when you need badges, secondary lines, or actions inside each row while keeping expand/collapse behavior.
- Set `showIndentGuides={false}` for a flatter explorer-style list.
- `disabled` on a node prevents selection and dims the row; expand chevrons remain for folders unless you hide them via custom content.
- Icons use Iconify strings (same as elsewhere in the library).

## CSS styling

`.ph-tree-view` is the stable identification hook for TreeView. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

Row selection and expansion use `aria-selected` and `aria-expanded`; variants use `data-variant`. Virtualization and pixel-based row/indent measurements are unchanged.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.
