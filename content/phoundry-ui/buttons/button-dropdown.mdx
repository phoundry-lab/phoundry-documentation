## Searchable menus

Set `searchable` to show a search input in each menu level (default: `false`). Filtering matches labels using a case-insensitive, trimmed substring; spaces inside the query are preserved. Each submenu searches only its own level, and each opening starts fresh. Empty results show “No results found”. Arrow Up/Down move through enabled results, Enter activates a result, and Escape returns from a submenu or closes the root menu.

```svelte
<ButtonDropdown {items} searchable>Choose action</ButtonDropdown>
```

## Usage tips

- Pass `items` as a function for lazy evaluation - useful when menu items depend on current state.
- Set `placement="bottom"` to center the menu beneath the button. Unsuffixed placements center on the corresponding edge; `-start` and `-end` align to its ends. Menus stay within the viewport.
- The dropdown uses the same `ContextMenu` overlay, so it requires `provideContextMenu()` (or `setupOverlays()`) in a parent layout.
- Set `showArrow={false}` to hide the chevron for a cleaner look (not used when `singleClickAction` is set).
- All six variants match `Button`: `primary` uses the dim accent surface, `secondary` uses the base surface, `outline` adds a border, `danger` uses danger colors, and `ghost` and `link` use transparent surfaces. Hover and active colors follow the same variant tokens. An open menu holds its trigger in the active style.
- The `xs`, `sm`, `md`, and `lg` sizes use the shared CSS control-height and icon-size tokens, matching `Button`. `fullWidth` stretches the whole control, including the shell in split mode.
- In split mode, the chevron segment's width equals the whole control's outer height, including for the outline variant. The segment keeps that width when space is constrained.
- Clicks have no wave animation. Loading spins the icon, and opening rotates the chevron; both respect reduced-motion preferences.

## Styling hooks

The stable root selector is `.ph-btn-dropdown`. Consumer `class` and `style` values apply to this root: the button in single mode and the outer shell in split mode. Native attributes, tooltip attachment, and the `element` binding still target the primary button. Part selectors are internal.

The root exposes `data-variant` and `data-size`. Visual customization uses `--ph-btn-radius`, `--ph-comp-h-xs` / `sm` / `md` / `lg`, and `--ph-comp-icon-xs` / `sm` / `md` / `lg` from the shared component stylesheet. The same optional `--ph-button-shadow`, `--ph-button-specular`, `--ph-button-shading`, and `--ph-text-shadow` overrides used by `Button` apply here.

Optional motion overrides are `--ph-motion-fast` (100ms for surface and chevron transitions), `--ph-motion-ease-out` (`ease-out`), and `--ph-motion-spin` (1000ms per loading rotation). Reduced-motion preferences disable these transitions and the spinner animation.
