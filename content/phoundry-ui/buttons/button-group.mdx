## Usage tips

- Set one item's `active` value to reflect selection. Each button exposes this state through `aria-pressed`; selecting an item is controlled by the Consumer's `onclick` handler.
- `secondary` and `outline` use `surface-overlay-active` for the selected segment. `ghost` uses `surface-overlay-hover`, matching `Button variant="ghost"`. Inactive hover colors also follow the corresponding Button variant.
- Items support `icon`, optional `label`, tooltip-based `title`, native button attributes, and additive classes and styles. Omit `label` (or use an empty string) for a square icon-only item; layout is derived from an icon or loading spinner without label text. Supply `aria-label` or `title` for its accessible name. The `iconOnly` item prop has been removed. Links are not supported.
- Loading replaces the item content with a spinner and disables its action. Disabled items cannot activate through the component's click handler.
- `sm`, `md`, and `lg` have outer heights of 1.5rem, 1.75rem, and 2rem with the shared defaults. Insets and borders stay inside those heights, so a group aligns with the same-sized Button or ButtonDropdown.

```svelte
<ButtonGroup
	items={[
		{ icon: PhiIcons.add, "aria-label": "Add", onclick: addItem },
		{ icon: PhiIcons.check, label: "Apply", onclick: applyChanges },
	]}
/>
```

## Styling hooks

The stable root selector is `.ph-btn-group`, with `data-variant` and `data-size` axes. Consumer `class`, `style`, and remaining div attributes apply to this root; item classes, styles, and native attributes apply to each button. Part selectors are internal.

The group consumes shared `--ph-comp-h-sm` / `md` / `lg` height tokens, `--ph-comp-icon-sm` / `md` / `lg` icon tokens, and `--ph-btn-radius`. It shares Button's `--ph-button-shadow`, `--ph-button-specular`, `--ph-button-shading`, and `--ph-text-shadow` tokens.

Indicator movement uses `--ph-motion-normal` (200ms), hover uses `--ph-motion-fast` (100ms), and both use `--ph-motion-ease-out`. Loading uses `--ph-motion-spin` (1000ms). Reduced-motion preferences disable movement, transitions, and spinner animation.
