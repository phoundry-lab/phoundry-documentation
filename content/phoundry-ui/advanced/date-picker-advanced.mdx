## Usage tips

- Use `minDate` and `maxDate` to constrain selectable dates.
- In `range` mode (when `includeEndDate` is true), the first click sets the start and the second click sets the end.
- Use `DatePickerAdvanced` with `showToggles={false}` for a compact calendar (same layout `DatePicker` uses internally).
- Set `weekStartsOn={1}` for Monday-first calendars (ISO standard).
- Use `formatDate` when the picker summary rows need to match a host application's date presentation.

## CSS styling

`.ph-date-picker-advanced` is the stable identification hook for DatePickerAdvanced. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

Calendar selection uses `aria-pressed` and separate range-state attributes. Day, month, year, time, and range behavior remain available.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.
