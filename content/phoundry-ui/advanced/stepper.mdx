## Usage tips

- Use `clickable` with `onstepchange` for wizard UIs where users can jump between completed steps.
- Mark optional steps with `optional: true` to display an "Optional" label.
- Use the `step` snippet prop for fully custom step indicators when icons + labels are not enough.
- `clickable` requires `onstepchange` - clicks on non-current steps invoke the handler.
- Vertical orientation works well in sidebars or narrow containers.

## CSS styling

`.ph-stepper` is the stable identification hook for Stepper. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

Orientation and step status drive CSS. The numbered indicator uses `--ph-comp-h-md`; step navigation and custom snippets retain their contracts.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.
