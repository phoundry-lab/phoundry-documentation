## Usage tips

- The `onmove` handler receives the full move event - you're responsible for updating column state immutably.
- Use the `card` snippet prop for custom card rendering (e.g. avatars, due dates, priority indicators).
- Column `color` is rendered as a header accent - use brand or status colors to differentiate lanes.
- Cards support `labels` for lightweight categorization displayed as tags.
- `DndGhost` and `DndIndicator` ship inside the component - import bundled styles so drag visuals match other DnD surfaces.

## CSS styling

`.ph-kanban-board` is the stable identification hook for KanbanBoard. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

Column and card styling is scoped locally. Consumer-provided card and label colors remain runtime values. Drag-and-drop callbacks are unchanged.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.
