## Usage tips

- Use `minDate` and `maxDate` to constrain selectable dates.
- In `range` mode, the first click sets the start and the second click sets the end.
- Set `weekStartsOn={1}` for Monday-first calendars (ISO standard).

## CSS styling

`.ph-date-picker` is the stable identification hook for DatePicker. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

`inputSize` continues to select the nested TextInput control size. Date formatting, range selection, and callbacks are unchanged.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.
