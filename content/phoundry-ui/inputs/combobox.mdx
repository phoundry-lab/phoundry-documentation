## Usage tips

- Use `onSearch` for server-side filtering - it debounces at 200 ms and replaces local filtering entirely.
- Combine `multiple` + `creatable` for a tag-input pattern where users can add arbitrary values.
- Provide the `option` snippet to render custom layouts (avatars, badges, etc.) inside each dropdown row.

## Footer actions

Pass `actions: MenuItem[]` to `combobox()`, `api.open()`, or `api.configure()` to pin menu items below the scrolling option list. They remain visible when you scroll or search, including when no options match. The footer supports Context Menu actions, boolean and radio items, separators, labels, groups, custom rows, and submenus.

```ts
import type { MenuItem } from "phoundry-ui";

const actions: MenuItem[] = [
	{
		type: "action",
		id: "refresh",
		label: "Refresh projects",
		preventClose: true,
		action: () => refreshProjects(),
	},
	{ type: "separator" },
	{
		type: "action",
		id: "new-project",
		label: "New project…",
		shortcut: "Mod+N",
		action: () => createProject(),
	},
];

api.open({
	anchor: trigger,
	options: projects,
	onchange: selectProject,
	actions,
});
```

Footer actions close the Combobox before running unless `preventClose: true`. Top-level action shortcuts also work while focus is in the option list or search field. Arrow keys move between options and footer rows; footer submenus and custom controls own their keyboard interaction.

The previous `{ id, label, run }` footer shape is replaced by the shared `{ type: 'action', id, label, action }` shape. `ComboboxAction` now aliases `ActionMenuItem`.

## CSS styling

`.ph-combobox-panel` is the stable identification hook for Combobox. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

Searchable option rows share the overlay-row visual contract. Active and selected rows use semantic state; keyboard and selection behavior are unchanged.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.
