## Styling

`.ph-status-checkbox` is the stable root identification hook. Styling is component-local vanilla CSS; `data-size` always identifies the selected size. `class` and `style` apply to the button. Indicator sizes use `--ph-indicator-sm` (0.875rem) and `--ph-indicator-md` (1rem), with `--ph-comp-icon-xs` / `--ph-comp-icon-sm` for icons. `--ph-indicator-icon-filter` controls the shared icon shadow. State colors still come from each state definition; state cycling and binding are unchanged. Internal part selectors and `--_ph-*` properties are implementation details. Filled indicators use the active Theme’s `--text-on-accent` foreground.
