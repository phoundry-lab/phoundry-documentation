## Usage tips

- Use for boolean settings that take effect immediately (e.g. dark mode, notifications).
- Prefer `Checkbox` over `CheckboxToggle` when the value is part of a form that requires explicit submission.
- The thumb has a press animation - users get tactile feedback on click.
- Pass a `name` prop for native form submission via hidden input.

## Styling

`.ph-toggle` is the stable root identification hook. Styling is component-local vanilla CSS; `data-size` always identifies the selected size. The root is the label wrapper when labelled and the switch button otherwise. `class` and `style` apply to that root; native attributes, attachments, and `bind:element` still target the button. Sizes remain `xs`, `sm`, and `md`. `--ph-toggle-thumb-shadow` controls the thumb shadow. Press and slide transitions respect reduced-motion preferences. Internal part selectors and `--_ph-*` properties are implementation details. Filled indicators use the active Theme’s `--text-on-accent` foreground.
