## Usage tips

- Use `indeterminate` for "select all" patterns where only some children are checked.
- Pass a `name` prop to render a hidden `<input>` for native form submission.
- When using without the `label` prop, supply `aria-label` or `aria-labelledby` on the control.

## Styling

`.ph-checkbox` is the stable root identification hook. Styling is component-local vanilla CSS; `data-size` always identifies the selected size. The root is the label wrapper when labelled and the control button otherwise. `class` and `style` apply to that root; native attributes, attachments, and `bind:element` still target the button. Indicator sizes use `--ph-indicator-sm` (0.875rem) and `--ph-indicator-md` (1rem), with `--ph-comp-icon-xs` / `--ph-comp-icon-sm` for icons. Customize the shared icon shadow with `--ph-indicator-icon-filter` and the surface shadow with `--ph-input-shadow`. Internal part selectors and `--_ph-*` properties are implementation details. Filled indicators use the active Theme’s `--text-on-accent` foreground.
