## Searchable

Set `searchable` to show a search field inside the dropdown. Search is off by default. Filtering matches option labels using a case-insensitive substring, ignores surrounding whitespace, and hides groups with no matches. It does not change the current selection until an option is chosen. The query resets whenever the dropdown closes.

<Example name="inputs/select/searchable" />

The search field receives focus when opened. Use Arrow Up/Down to navigate matching enabled options and Enter to select. Spaces remain editable text; Escape closes the dropdown and returns focus to the trigger. An empty result set displays “No results found”.

## Usage tips

- Use `variant="ghost"` when the select is inline within a toolbar or header.
- Pass `shrink` to prevent the trigger from stretching to full width.
- Combine `invalid` + `error` for form validation; the error renders below the trigger.
- The dropdown renders as a portal-based overlay for correct z-index stacking.
- Full keyboard navigation: Arrow keys, Enter/Space to select, Escape to close.
- Pass `name` to emit a hidden input for plain HTML forms alongside the visible button trigger.

## Styling

`.ph-select` is the stable root identification hook. Styling is component-local vanilla CSS; `data-size` always identifies the selected size on the trigger. The root wrapper is `.ph-select`; the trigger button is `.ph-select-trigger`. Consumer `class`, `style`, native attributes, attachments, and `bind:element` still target the trigger. The trigger emits `data-size`, `data-variant`, and `data-placeholder`, with open and invalid states represented by `aria-expanded` and `aria-invalid`. The wrapper emits `data-shrink`. Trigger heights use `--ph-comp-h-sm` (1.5rem) and `--ph-comp-h-md` (1.75rem), with `--ph-comp-icon-sm` / `--ph-comp-icon-md` for icons. The shared surface shadow uses `--ph-input-shadow`; the dropdown retains its fixed option scale. Internal part selectors and `--_ph-*` properties are implementation details.
