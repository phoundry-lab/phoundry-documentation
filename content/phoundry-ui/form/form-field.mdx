## Usage tips

- The `error` prop takes priority over `description` - only one displays at a time.
- Use `{#snippet children(control)}` and spread `{...control}` onto the focusable input. This links the label, helper/error text, invalid state, and required semantics, including when `id` is generated.
- Pass a Snippet for `label` when you need custom markup (e.g. an icon next to the label text).
- Wrap any input component - `TextInput`, `Select`, `Textarea`, etc.

## Styling

`.ph-form-field` is the stable root hook. Consumer `class` values are additive, and `style` applies to that root. Styling uses vanilla CSS with semantic state attributes. Label and description/error IDs remain linked through the `children(control)` snippet. Spread those supplied attributes onto the one focusable input. Generated IDs are stable across server rendering and hydration. `disabled` dims the wrapper; disable the actual control separately. The wrapper emits `data-disabled`; helper text emits `data-error`. Internal part selectors and `--_ph-*` properties remain implementation details.
