## Usage tips

- The default overlay shows "Drop to upload" on valid drag and "Invalid file type" when files don't match `accept`.
- Use the `active` snippet to fully customize the drag-over overlay.
- The `accept` array supports MIME types (`'image/*'`), exact MIME (`'application/pdf'`), and extensions (`'.csv'`).
- Files that don't match `accept` are silently filtered out of the `ondrop` callback.

## Styling

`.ph-drop-zone` is the stable root hook. Consumer `class` values are additive, and `style` applies to that root. Styling uses vanilla CSS with semantic state attributes. The root exposes `data-dragging`, `data-invalid`, and `aria-disabled`. CSS owns valid/invalid overlay colors, while drag counters, accept filtering, drop callbacks, and the optional active snippet retain their existing behavior. Overlay text uses the Theme’s on-accent foreground; reduced motion removes its color transition. Internal part selectors and `--_ph-*` properties remain implementation details.
