## Usage tips

- The `first` and `second` props are Svelte snippets - use `{#snippet first()}...{/snippet}` syntax.
- The container must have a defined height (e.g. `h-full`, `h-screen`) for the split to render correctly.
- Use `bind:size` for two-way binding to persist or display the pane size.
- Set `max` to prevent the first pane from consuming the entire container.

## CSS styling

`.ph-split-pane` is the stable identification hook for SplitPane. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

`size`, `defaultSize`, `min`, `max`, and `handleSize` retain their pixel-based measurement contract. Direction and drag state are semantic attributes; fixed divider styling lives in CSS.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.
