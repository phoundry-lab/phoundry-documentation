## Usage tips

- Pass `items` for full control, or `target` to auto-discover headings from a container.
- In auto mode, headings without `id` attributes get one assigned automatically (slugified from text).
- Use `headingSelector` to control which heading levels are included (e.g. `"h2, h3"` or just `"h3"`).
- Set `direction="horizontal"` for compact inline navigation. Nesting is disabled in horizontal mode.
- The component renders nothing when there are no items - safe to include in layouts unconditionally.
- Add to a layout file with `target={mainEl}` to get a page ToC on every page automatically.

## CSS styling

`.ph-anchor` is the stable identification hook for Anchor. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

Scroll tracking and measured ink-indicator geometry are unchanged. Direction and active-link styling are represented by attributes.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.

Anchor scrolling is immediate when reduced motion is requested; otherwise it remains smooth.
