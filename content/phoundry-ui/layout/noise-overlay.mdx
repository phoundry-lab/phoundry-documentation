Full-viewport static grain using an SVG feTurbulence (fractal noise) + feColorMatrix (desaturate) filter chain. Renders a fixed, pointer-events-none layer meant for a single use near the app root. Prefer opacity around 0.05–0.12 at normal zoom.

```ts
import { NoiseOverlay } from "phoundry-ui";
```

## Root layout

Mount once inside your top-level `+layout.svelte` (or app shell). Keep `zIndex` under your modal / tooltip layer; the component defaults to `1`. The layer uses `pointer-events: none` so it never steals focus or clicks.

```svelte
<script>
	import { NoiseOverlay } from "phoundry-ui";
</script>

<div class="relative min-h-svh">
	<NoiseOverlay />
	<div class="relative z-10">
		{@render children?.()}
	</div>
</div>
```

## CSS styling

`.ph-noise-overlay` is the stable identification hook for NoiseOverlay. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

Position uses `data-position`. Opacity, stacking, and blend-mode props keep their existing behavior.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.
