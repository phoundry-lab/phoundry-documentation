## Usage notes

- Mount `DndGhost` and `DndIndicator` once per layout surface that uses this kit (the docs page mounts them below the examples).
- Attach `dndList` on the scroll/container that wraps draggable rows; attach `dndItem` on each row (up to three levels of wrapper depth are considered when resolving drop slots).
- Interactive controls inside a row (buttons, inputs, links) block drag initiation unless wrapped outside the hit-tested subtree per `dndItem` rules.
- `KanbanBoard` composes these attachments for multi-column cards.

Touch input does not initiate the shared desktop drag session. Native touch scrolling and contextual holds remain available; `onClickWithoutDrag` applies only to supported drag-session pointers.

## CSS styling

`.ph-dnd-ghost` is the stable identification hook for Drag-and-drop previews. Part selectors and `--_ph-*` properties are internal. Component CSS is scoped and unlayered; Consumer classes remain additive and utility overrides may lose precedence.

The insertion indicator uses `.ph-dnd-indicator`. Measured coordinates cross into CSS through private custom properties. Existing drag/drop attachments and callbacks remain available.

Keep the shared component stylesheet and a named Theme imported. Decorative motion respects reduced-motion preferences.

Drag state uses `data-ph-dnd-active="true"` on the body and
`data-ph-dnd-dragging="true"` on the dragged source. Replace custom selectors
that used `.dnd-active` or `.dnd-dragging`. Drag transitions use shared motion
tokens and stop under reduced motion. The unused `.phi-dnd-poof` helper was
removed.
