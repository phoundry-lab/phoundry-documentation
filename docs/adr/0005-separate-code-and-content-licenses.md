# License tooling and content separately

Static-site, package, manifest, validation, and generation code in `phoundry-documentation` is MIT-licensed. Canonical documentation prose and media are licensed under Creative Commons Attribution 4.0, while Phoundry names and marks remain separately reserved.

Repository notices and path-level license files must make the boundary explicit so contributors and package consumers do not mistake documentation content for MIT code or infer trademark permission from the content license.
